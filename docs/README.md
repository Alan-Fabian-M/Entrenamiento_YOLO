# Documentación del proyecto — InmobiliariaVR Backend de Visión

Esta carpeta (`docs/`, raíz del repo) tiene la documentación de **alto
nivel**: de qué trata el proyecto, qué se quiere conseguir, y las reglas
duras que no se pueden romper al seguir trabajando en él.

Para el detalle técnico línea por línea de cada fase (evidencia, benchmarks,
decisiones de implementación) ver `YOLO/docs/` — en particular
[`YOLO/docs/05_Reentrenamiento_CubiCasa5K_y_Deteccion_Multicuarto.md`](../YOLO/docs/05_Reentrenamiento_CubiCasa5K_y_Deteccion_Multicuarto.md)
para el estado más reciente y los próximos pasos priorizados.

1. [**00_Objetivos_y_Vision.md**](00_Objetivos_y_Vision.md) — qué es el
   proyecto, qué problema resuelve, cómo se ve "terminado".
2. [**01_Reglas_del_Proyecto.md**](01_Reglas_del_Proyecto.md) — invariantes
   que no se pueden romper (el contrato JSON con Unity, límites del dataset,
   convenciones de escala) y por qué existen.
3. [**02_Estado_Actual.md**](02_Estado_Actual.md) — dónde está el proyecto
   ahora mismo y qué sigue, en un vistazo rápido (con enlaces al detalle
   técnico completo).
